# Security

Please report a security problem privately, rather than in a public issue: use [Report a vulnerability](https://github.com/drormos/metra/security/advisories/new) on GitHub, or email metra.application@gmail.com. You'll get a reply within a few days.

Metra has no network access, no accounts and no server: the main risks are in what it stores on the phone (songs and settings in the app's private storage) and in its dependencies. Fixes ship as a new build through Google Play.
