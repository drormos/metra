# What's new in Metra

Newest first. The top version's lines are also the Play Store release notes.

## 1.4.0 · Oct 2026
- Add a new song straight to a set
- Change a song right on the main screen, then Save
- Drag a list's handle up for more room
- Example songs and a set to try on a fresh install
- Smoother number and name changes; beat lights that strike and fade
- Larger text, TalkBack and "Remove animations" support
- Songs and sets are managed in the lists; the old pages are gone

## 1.0–1.3 · Sep–Oct 2026
- Test builds for friends: the click, songs, setlists, polyrhythm, click sounds, and the Menu
